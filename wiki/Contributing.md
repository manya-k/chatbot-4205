# Contributing

How to contribute
- Open an issue for bugs or feature requests.
- Fork the repository and create a branch:
  - git checkout -b feat/short-description
- Create a small, focused pull request with tests where applicable.

Code style
- Follow the style guidelines in CONTRIBUTING.md or the codebase. Use linters and formatters.

Pull request checklist
- Is there a description of the change?
- Are tests added or updated?
- Does the code pass CI?
- Are docs updated if behavior changed?

Reporting security issues
- Do not open a public issue. Contact the repository owner directly or use a private channel for sensitive disclosures.
